      인식 설정

      켜면 색·모자를 무시하고 대상 종류만 맞으면 바로 울립니다. Smart Motion Radar와 같은 판단 방식이라 성능 비교 실험에 씁니다.

      Lite2는 멀리 있는 작은 대상을 더 잘 찾지만 느립니다.

      낮추면 더 많이 찾지만 엉뚱한 박스도 늘어납니다.

      /

      최근 N프레임 중 K번 이상 조건과 맞아야 경보가 울립니다. 1 / 1이면 투표 없이 즉시 울립니다.

      상의(또는 차체) 영역에서 목표 색이 이 비율 이상이면 일치로 봅니다.

      노란 실내등처럼 조명 색이 치우칠 때 흰 옷이 주황으로 보이는 것을 줄입니다.

      대상 박스가 1초 사이 30% 넘게 커지면 빠른 경고음으로 한 번 더 알립니다.

      모자 판정 방식

      기본 방식은 흰색·색 있는 모자와 안전모에 잘 맞고, 검은 모자는 머리카락과 구분하기 어렵습니다. 검은 모자까지 잡으려면 학습 모델을 연결하세요.

      model.json, weights.bin, metadata.json 세 파일을 함께 고르세요.

      학습 모델이 연결되지 않았습니다.

      1. teachablemachine.withgoogle.com에서 이미지 프로젝트 → 표준 이미지 모델을 만듭니다.
      2. 클래스 두 개를 ‘모자 씀’, ‘모자 안 씀’으로 이름 붙입니다.
      3. 각 클래스에 머리 부분이 크게 나온 사진을 100장 이상 넣습니다. 여러 사람, 여러 각도, 검은 모자도 꼭 포함하세요.
      4. 모델 학습 → 모델 내보내기 → 업로드한 뒤 공유 링크를 위 칸에 붙여 넣습니다.
      발표용 비교 실험 방법
      1. 같은 테스트 영상을 준비합니다. 예: 행인 20명 중 빨간 옷 5명, 차량 30대 중 흰 트럭 4대.
      2. ‘인식 설정’에서 비교 모드를 켜고 영상을 재생합니다. 경보마다 정답 · 재경보 · 오탐을 누르고 CSV로 저장합니다.
      3. 기록을 지우고 비교 모드를 끈 뒤 같은 영상을 다시 재생해 똑같이 표시합니다.
      4. 확정 투표를 1 / 1로 바꿔 한 번 더 돌리면 투표(시간 필터)의 효과만 따로 보여줄 수 있습니다.
      5. Smart Motion Radar도 같은 영상을 모니터에 틀고 휴대폰으로 비춰 경보 수를 셉니다. 정밀도 · 재현율 · 오탐/분을 한 표로 비교합니다.
